## Contract and changes

- Added staff-only `GET /api/dashboard`, mounted at `/api/dashboard`; authenticated ADMIN/AGENT members may read the selected organization, while customers receive 403 and inaccessible organization selectors return 404.
- Rejects every query parameter with 422; returns `Cache-Control: no-store`.
- Captures one UTC `evaluationTime` and runs membership revalidation plus tenant-scoped aggregates in one PostgreSQL repeatable-read transaction.
- Returns `totalTickets`, exact status and priority maps with zero-filled enum values, overdue count, and deterministic per-agent workload rows.
- Overdue means `dueAt < evaluationTime` and status is neither RESOLVED nor CLOSED. Null due dates and tickets exactly at the evaluation time are not overdue.
- Workload rows include active AGENT memberships, including agents with zero work; count assigned OPEN and IN_PROGRESS tickets, and omit inactive agents and customers. This is documented as an application assumption in `docs/assumptions.md` and `docs/api.md`.
- Corrected the assumptions role matrix to distinguish adding a comment (non-closed only) from reading comments/activity on any visible ticket, including closed tickets.
