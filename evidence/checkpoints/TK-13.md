## Contract and changes

- Added `GET /api/tickets` with required session/current organization. ADMIN/AGENT see organization tickets; CUSTOMER is restricted to their own requester IDs by the mandatory policy predicate.
- Strict optional status/priority/assignee/customer/search filters. `unassigned` maps to a null assignee. UUIDs canonicalize to lowercase. Search trims and performs case-insensitive substring matching over title and description. Unknown/malformed fields, blank/long search, and tenant/body-shaped query fields return 422.
- Every caller filter is ANDed with mandatory tenant/customer policy; total and items are queried in one PostgreSQL RepeatableRead transaction. Results omit descriptions and secrets, are ordered by `createdAt DESC, id DESC`, and capped at 100 while TK-14 adds explicit page controls.
- Docs and README describe current endpoint coverage and outstanding pages/detail/update/UI work.

## Decisions and limits

- Page navigation, explicit requested page size, tie-heavy pagination regression cases and larger result behavior are TK-14, not claimed complete here.
- Search is a case-insensitive literal substring match, including `%`, `_`, and `\`, not PostgreSQL full text. Regression tests showed unescaped underscore was a wildcard; the query now escapes LIKE metacharacters. Title and description are searched; description is not returned in the list DTO.
- A07 remains partial until dashboard exists. A17 remains partial pending browser support. A18 passed its API-only acceptance scope after independent post-correction replay/review.
