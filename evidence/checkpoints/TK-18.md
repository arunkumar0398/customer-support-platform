## Contract and changes

- Added authenticated `GET /api/tickets/{ticketId}/activity` with strict bounded `page`/`pageSize` validation and `{ items, total, page, pageSize }` response.
- Activity visibility reuses `ticketScope`, including active organization and customer ownership. Event queries include organization and ticket IDs, return a selected DTO, and order by `createdAt ASC, id ASC` in a repeatable-read transaction.
- The endpoint is read-only. No event update/delete routes are registered. Authentication middleware sets `Cache-Control: no-store` before route validation.
- Added real disposable PostgreSQL fault injection: a scoped trigger rejects an activity insert during a ticket update; the API returns sanitized 500, ticket and events remain unchanged, and recovery succeeds after trigger removal.
- Updated `docs/api.md` with the endpoint contract. Comments remain TK-19.
