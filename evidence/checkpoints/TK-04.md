## Changes

- Pinned Prisma CLI, generated client, and PostgreSQL adapter to 7.10.1; configured the Prisma 7 `prisma-client` generator with an ignored output path under `api/src/generated/prisma`.
- Added `Organization`, `User`, `Membership`, and `MembershipRole` models. Membership uniqueness is `(organizationId, userId)`, with organization and user foreign keys and a user-first active-membership lookup index.
- Added a database check that rejects empty, padded, or mixed-case email values; the future service must normalize email before writing.
- Added `api/src/db/client.ts` using `@prisma/adapter-pg`, with bounded pool settings and lazy construction.
- Added a Prisma config that loads the repository-root `.env` for migrations and uses an unreachable placeholder URL when no direct URL is configured, allowing client generation without a database while failing closed for migration attempts.
- Added `scripts/migrate-test-database.mjs` and `npm run db:migrate:test`. It validates both the test URL and PostgreSQL-reported database/user identity before forwarding the URL to the Prisma migration command.
- Added six actual PostgreSQL integration tests for row insertion, duplicate membership, missing organization/user foreign keys, normalized email, and the user-first membership index.
