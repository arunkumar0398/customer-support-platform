## Changes

- Added `TicketStatus`, `TicketPriority`, and `ActivityEventType` enums and Prisma models for `Ticket`, `Comment`, `ActivityEvent`, and `Session`.
- Tickets use organization-scoped positive `ticketNumber`, positive version (default 1), default `OPEN`/`MEDIUM`, optional due time, and tenant-first list/filter/workload/overdue indexes.
- Added same-organization composite foreign keys for requester, assignee, comment ticket/author, and activity-event ticket/actor. The nullable Prisma assignee relation stores a nullable organization scalar too; SQL checks require both assignee scalars to be null or the assignee scope to match the ticket organization.
- Added a unique 64-character session token-digest field, user FK, expiry/revocation/last-seen timestamps, and user/expiry index. Raw session tokens are not stored.
- Added migration `20261026193000_ticket_comment_activity_session` and updated the data-model documentation to match the implemented field/index names. Activity events are documented as append-only at the application contract; no event-writing service exists yet.
- Added 14 real PostgreSQL tests for same-org and cross-org references, org-scoped numbering, positive version/number, session constraints, and index column order.
