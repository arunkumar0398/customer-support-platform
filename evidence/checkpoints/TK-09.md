## Changes

- `api/src/middleware/active-membership.ts` requires a preceding authenticated server context and a single canonical UUID in `X-Organization-ID`. It queries the current user's active membership in PostgreSQL and derives organization/user/role from the result. It never derives authority from body/query role, user, or organization fields.
- Missing selector returns 400 `ORGANIZATION_REQUIRED`; malformed/ambiguous selector returns 400 `INVALID_ORGANIZATION`; inactive/removed/foreign/nonexistent membership returns the same non-disclosing 404. Current role changes and membership revocation apply on the next request with the same session.
- `api/tests/auth/active-membership.test.ts` exercises production authentication/membership middleware through test-only Express context routes with real persisted sessions and isolated PostgreSQL fixtures. No product context-inspection endpoint was added. Upcoming product routers must mount the middleware chain before object/role policy enforcement.
- `docs/api.md` documents selector semantics, middleware ordering, and the limits of this foundation.
- The evidence commit refreshes the acceptance ledger's stale TK-02-only introduction and adds partial-evidence links without changing any result. `CURRENT_HANDOFF.md` records the next task and review state.
