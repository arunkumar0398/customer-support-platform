## Changes and design defaults

- Added `api/src/modules/auth/{routes,service,session}.ts` and `api/src/middleware/authenticate.ts`; `createApp` supports explicit configuration/client injection while the existing default app/serverless export is preserved.
- Login verifies the existing fixed-parameter salted scrypt hash format, performs a dummy derivation for unknown accounts, normalizes email, and validates strict input allowlists/ranges. Only public user and current active membership fields are returned.
- Sessions use 32 random bytes, PostgreSQL stores only the SHA-256 token hash, and expiry is enforced server-side after two hours. Login rotates/revokes a supplied old session in the same transaction as creating the new session. Logout persists revocation; expired/revoked/unknown/ambiguous cookies fail closed.
- Host-only cookies use `HttpOnly`, `SameSite=Lax`, `Path=/api`, and `Secure` in production. Auth responses are `no-store`.
- Login requires the exact configured origin and a custom non-simple header. Other authenticated unsafe methods require that origin and an HMAC CSRF token bound to the specific session, compared in constant time. No cross-origin CORS policy is enabled. Missing/invalid config fails closed before session creation; production requires an HTTPS origin.
- Login limits are five attempts per normalized account and twenty per socket IP per fifteen minutes, with bounded process-local state and `Retry-After`. Forwarding headers are not trusted. This is a local single-process control: restarts/replicas/serverless require a shared/provider limiter before release; proxy clients may share a budget.
- Updated README and `docs/api.md` with only implemented behavior, security defaults, and limitations. There is still no sign-in screen or application listener/launch command.

The expiry, cookie name/path, request header names, and local limits are implementation defaults within the approved design, not employer requirements. No architectural baseline deviation, hosted resource, or production deployment was introduced.
