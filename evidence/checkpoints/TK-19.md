## Contract and changes

- Added `GET /api/tickets/{ticketId}/comments` and `POST /api/tickets/{ticketId}/comments`.
- All roles may read visible conversation history. Admins and agents may comment within their active organization; customers may comment only on their own tickets. The current active membership is reloaded after taking the organization lock before writes.
- History remains readable when a ticket is CLOSED; adding a comment to a visible CLOSED ticket returns `409 TICKET_CLOSED`. Inaccessible or absent tickets return the same generic 404.
- POST accepts only a trimmed `body` from 1–10,000 characters. GET uses bounded page/pageSize and deterministic `createdAt ASC, id ASC` order. Both endpoints return selected DTO fields only.
- A comment and its `COMMENT_ADDED` event (containing only the comment ID) commit in one transaction. A trigger-based PostgreSQL test proves comment rollback if event insertion fails.
- Updated `docs/api.md` with comment endpoints, bounds, visibility, event and error contracts, and corrected stale endpoint/policy statements.
